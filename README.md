# Banking Customer Churn Dashboard

A Power BI dashboard analyzing banking customer churn patterns and insights.

Project Overview
Customer retention is crucial for the banking sector. This dashboard provides actionable insights into customer behavior, demographics, and product engagement to help reduce churn rates and improve retention strategies.

## Key Metrics & KPIs
* **Total Customers:** 2,000+
* **Churned Customers:** Tracked dynamically across segments
* **Churn Rate:** ~20%
* **Active Members & Retained Customers:** Monitored to evaluate engagement levels

## Key Insights & Visualizations
* **Age Group Distribution:** Analyzed using a custom clustered column chart to identify which age brackets experience the highest churn.
* **Geography & Gender Impact:** Evaluated churn distribution across regions and gender segments.
* **Product Engagement:** Examined how the number of products held and active membership status affect customer retention.
* **Complaints & Satisfaction:** Integrated satisfaction scores and customer complaints to track core dissatisfaction triggers.

## Technical Stack & Tools
* **Tool:** Power BI Desktop
* **Data Modeling & Calculations:** DAX (Data Analysis Expressions) for creating custom columns like Age Group and percentage measures.
* **Version Control:** GitHub for project documentation and source file management.
